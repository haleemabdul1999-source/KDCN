# Known limitations & technical-debt register

Honest status of Release 1. Severity: **H** must resolve before live launch · **M** before scale-up · **L** later.

| #   | Area                                                                            | Limitation                                                                                                                                                                                                                                   | Sev | Remedy                                                                               |
| --- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | ------------------------------------------------------------------------------------ |
| 1   | Payments                                                                        | Paystack adapter has **not been exercised against the Paystack sandbox** (no outbound access during development). Only contract tests with a stubbed `fetch`.                                                                                | H   | Run the activation checklist in PAYMENTS.md with test keys                           |
| 2   | Payments / legal                                                                | Settlement model undecided: `MANUAL_RECORD` routes merchant funds through KDCN (possible regulatory implications); split-settlement refund behaviour with subaccounts unconfirmed                                                            | H   | Legal + provider confirmation; prefer `PROVIDER_SPLIT`                               |
| 3   | Notifications                                                                   | Email/SMS/WhatsApp use the **log driver only** — nothing is delivered to real recipients (password-reset links, order updates, guest tracking links). In-app notifications work.                                                             | H   | Implement SMTP/transactional email and SMS (e.g. Termii) adapters (`ChannelAdapter`) |
| 4   | Deployment                                                                      | Dockerfiles and docker-compose **not built/tested** here (no Docker daemon). No infrastructure-as-code. No production deployment.                                                                                                            | H   | Build images in CI; add IaC for the chosen platform                                  |
| 5   | Monitoring                                                                      | No error-tracking SDK wired (Sentry or equivalent); alerts not configured                                                                                                                                                                    | H   | See OPERATIONS.md                                                                    |
| 6   | Storage                                                                         | Local-disk storage only; requires a persistent volume and a single API instance (or shared FS). No malware scanning of uploads. No image resizing/thumbnails (originals served, ≤5 MB).                                                      | M   | S3-compatible driver + scanning + resized variants                                   |
| 7   | Auth                                                                            | No email verification at registration; no MFA for merchant owners; no self-service staff MFA reset                                                                                                                                           | M   | Add verification emails once email delivery exists                                   |
| 8   | Rate limiting                                                                   | In-memory, per instance; correct client IP needs `TRUST_PROXY=true` and an `X-Forwarded-For`-appending load balancer                                                                                                                         | M   | Edge/WAF limits or shared store when scaling out                                     |
| 9   | Encryption keys                                                                 | Single `DATA_ENCRYPTION_KEY`; no key versioning/rotation tooling                                                                                                                                                                             | M   | Add key IDs to the `enc:` prefix and a re-encryption job                             |
| 10  | Money                                                                           | Amounts are 32-bit integers (≤ ₦21.4m per amount; checkout caps at ₦20m)                                                                                                                                                                     | L   | Migrate to `bigint` before wholesale (ADR 0004)                                      |
| 11  | Search                                                                          | PostgreSQL FTS (`simple` config + trigram) — no synonyms/Hausa stemming; relevance tuning is basic                                                                                                                                           | L   | Synonym dictionary; consider a search service only at real scale                     |
| 12  | Catalogue                                                                       | No shared-catalogue matching (each merchant creates its own product); variant options are free-text                                                                                                                                          | L   | Release 2/3                                                                          |
| 13  | Analytics                                                                       | Behavioural events can be inflated by bots; conversion is period-based, not cohort-based; no export                                                                                                                                          | L   | Bot filtering, cohort reports, CSV export                                            |
| 14  | Fulfilment                                                                      | Manual dispatch only; no courier API, no live tracking (UI says so); collection-point operations (desk staff app) not modelled                                                                                                               | M   | Logistics adapter per partner                                                        |
| 15  | Disputes                                                                        | Evidence file upload not exposed in UI (API stores `evidenceKeys` but no upload endpoint for disputes yet)                                                                                                                                   | M   | Add evidence upload endpoint using the private bucket                                |
| 16  | Admin                                                                           | No bulk CSV exports for finance reconciliation; payouts recorded one batch reference at a time                                                                                                                                               | M   | Export endpoints                                                                     |
| 17  | Web                                                                             | CSP allows inline scripts (no nonce); no PWA/offline support; images served unoptimised through the API                                                                                                                                      | L   | Nonce-based CSP; image CDN                                                           |
